# 846 Digital — сайт-визитка Готовый статический одностраничный сайт компании. Для работы не требуется сборка или серверная часть. ## Быстрый запуск Откройте файл `index.html` в браузере. Для локального запуска через простой веб-сервер: ```bash python3 -m http.server 8080 ``` После запуска откройте `http://localhost:8080`. ## Публикация на GitHub Pages 1. Создайте репозиторий, например `846digital.github.io`. 2. Загрузите в корень репозитория `index.html`. 3. Откройте **Settings → Pages**. 4. В разделе **Build and deployment** выберите **Deploy from a branch**. 5. Укажите ветку `main` и папку `/ (root)`. 6.
